- Stage D writer learning lives in pure `learning.ts` (+ best-effort `learningRepo.ts`, owner-only `writer-learning` function): signals come only from stored findings and outcomes, a recommendation needs recurrence (≥3 sections, ≥2 chapters) plus an author-approved or proven signal, detector signals are low-weight and never sufficient, overlays are new versioned rows (never edits to base profiles; slider nudges clamped to ±2), and only active, pinned overlays reach the dynamic prompt tail in `analyze_and_rewrite` mode.
- Paid naturalness A/B experiments run only through pure `_shared/writers/abExperiment.ts`: worst-case cost is reserved before every call (counted input + max output, uncached rates, markup), unpriced models and fallbacks are refused, and all three texts (original, flawed copy, revised) are returned without writing any book data.
- All "how much changed" checks (naturalness rewrite budget, continuity revision ratio) use the word-level diff in pure `_shared/writers/textDiff.ts`, always against the original baseline: unchanged text between separate edits never counts, moved passages count as delete+insert.
